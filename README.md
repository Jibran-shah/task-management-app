
# Task Management App

A simple task management application designed to help users create, organize, update, and track their daily tasks efficiently.

## Features

- Create new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Organize and manage daily tasks
- Track task completion
